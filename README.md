# 六十路の古年譜・預言書

ブラウザの現在年を対象に、選択した80〜60年前の年の歴史からAIが予言を生成するStreamlitアプリです。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

## AIの接続設定

Streamlit Community CloudでこのアプリのSettings → Secretsに、以下を登録してください。
ローカルでは環境変数または `.streamlit/secrets.toml` を使用できます。

```toml
OPENAI_API_KEY = "ご自身のOpenAI APIキー"
OPENAI_MODEL = "gpt-6-sol"
```

APIキーはGitHubやチャットに貼り付けず、Secretsに保存してください。
OpenAI APIには利用可能なモデルとAPI課金の設定が必要です。
OPENAI_MODELは任意です。省略時はgpt-6-solを使用します。
キーが未設定でも歴史とニュースは表示し、AI欄で設定を案内します。

## 動作

- 対象年はブラウザの端末時刻から取得し、開いたままの年越しも定期確認します。
- 年の選択範囲は今年の80年前〜60年前の21年（両端の差は20年）です。
- 初期選択は60年前。画面表示・年の変更・再取得のたびに、選択年のWikipedia日本語版をMediaWiki APIから取得します。
- 「出来事」節を最大36件、年間に分散して抜粋し、出典の版と取得時刻を表示します。
- AIには選択年の出来事と関心テーマを渡し、今年の3つの仮説と過去とのつながりを生成させます。ニュース欄は別表示で、AIの根拠には使用しません。
- 初回は自動生成します。同じセッションで年・主題・歴史の版・モデルが同じ場合は予言を再利用します。再取得ボタンでは歴史もAI予言も更新します。
- 通信失敗時はエラーを表示し、架空の歴史や以前の別年の予言で代用しません。

予言は歴史の類似を用いた創作の仮説です。
歴史の抜粋はWikipediaより。出典リンクから版と著者履歴を確認できます。CC BY-SAで提供される資料です。
